Mac System Monitor support.

Requirements, setup, settings, troubleshooting, privacy, and security information for Mac System Monitor.

Public support

Use GitHub Issues for setup help and bug reports. Use private vulnerability reporting for sensitive security reports.

Requirements

Supported

  • Apple silicon Mac (arm64)
  • macOS 12 or later
  • Stream Deck 7.1 or later
  • A supported Stream Deck keypad model

Not required

  • No cloud account
  • No API key or credentials
  • No root access
  • No additional macOS privacy permission
Intel Macs are not supported. Specialist Apple silicon readings may become unavailable after macOS or hardware changes; the plugin shows an explicit unavailable state instead of substituting values.

Get started

  1. Install Mac System Monitor from Elgato Marketplace.
  2. Open Stream Deck and drag an action from the Mac System Monitor category onto a key.
  3. Wait one or two refresh intervals for metrics that need an initial baseline.
  4. Select the key and configure the controls applicable to that metric in the Property Inspector.
  5. For actions with multiple views, press the physical key once to advance exactly one view.

Presses on multi-view actions only change that key’s view. They do not modify macOS settings or start an additional sampler, timer, or process.

Settings

Per-key presentation

Where available, choose the active view, accent color, value size, optional secondary information, process row count, and metric-specific source.

Refresh and history

Choose Fast, Normal, or Efficient refresh per visible key. The shared collector uses the fastest visible request for that metric. History-capable views offer bounded charts and 30-second, one-minute, or two-minute ranges.

Warnings

Enable warning colors and set ordered metric-specific limits. Runtime errors, stale data, and unavailable states remain visible even when metric warning colors are off.

Defaults

Reset affects only the selected key and is available only when its settings differ from the metric defaults.

Troubleshooting

A key shows “Loading”

Some counters require a baseline. Keep the key visible for at least two selected refresh intervals.

A value shows “Unavailable” or “—”

The selected sensor or channel is not currently available. Try another view where applicable. Do not disable Gatekeeper or manually remove quarantine attributes.

Specialist Apple silicon readings disappeared after an update

GPU, temperature, power, Neural Engine, and fan readings use bundled local telemetry backed by private macOS interfaces. Compatibility can change with macOS or hardware revisions. Report the exact macOS, Stream Deck, and plugin versions.

Settings do not appear to change the key

Confirm that the intended key is selected in Stream Deck. Settings are stored per key. A hidden control is intentionally unavailable in the current view when it cannot affect the rendered result.

Installation is blocked

Stop and report the exact Stream Deck or macOS error. Do not bypass Gatekeeper, modify the installed bundle, or remove quarantine manually.

Privacy

Mac System Monitor runs locally. It has no analytics, cloud account, configured external network endpoint, remote script, or runtime download. Communication with Stream Deck and the bundled helpers remains local to the Mac.

  • Measurements remain in the local plugin process and visible keys.
  • History is bounded to at most two minutes and discarded after the final subscriber disappears.
  • Process names exist only in the current snapshot; the plugin does not write them to history, logs, or settings.
  • No credentials, cookies, browser storage, or product database are used.

Security and contact

The plugin invokes only fixed local executables and fixed argument arrays. It does not expose arbitrary commands, URLs, or collector arguments.

Support: Open a GitHub issue
Sensitive security reports: Report a vulnerability privately.

When reporting an issue, include macOS version, Stream Deck version, plugin version, affected action/view, and the exact visible error. Never send passwords, tokens, private keys, or complete credential files.
