# Security policy

## Supported versions

Security reports are accepted for the latest Marketplace version of Mac System Monitor.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting:

https://github.com/msimon-labs/mac-system-monitor-support/security/advisories/new

Do not open a public issue for a suspected vulnerability. Do not include passwords, tokens, private keys, cookies, complete credential files, private process names, or other personal data.

For ordinary setup problems and non-sensitive bugs, use GitHub Issues:

https://github.com/msimon-labs/mac-system-monitor-support/issues
